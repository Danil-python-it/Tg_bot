# Tg_bot
Бот-сервис, позволяет упростить работу в сферах логистики, делегирование и т.д.

## Система ролегого распределения прав

Данная программа реализованная на системе ролей,
Где каждая роль это лишь ярлык дляопределённого набора правил, которыми наделен владелец этой самой роли.
В системе есть как заготовленные наборы правил, так и возможность создавать новые.

Сейчас в программе есть следущие наборы правил 
1. admin - 
Предполагаемые обязанности: сотрудник с такой ролью ответсвеннен за работоспособность всей эко=системой программы под конкретного руководителя,
в его правах есть возможность влиять на распределения ролей, создания новых, добавления новых людей и в случае необходимости связи с теми, кому необхадима тех-поддержка
2. employer - 
Этот участник является самим работодателем, это человек наделенный всеми правами, просмотр любых таблиц, возможность просмотра бухгалтерии, или трекер деятельности исполнителей.
3. accountant - 
эта роль бухгалтера, в его распарежение все необходимые инструменты для видения бух отчета, начиная от работ с прайс листами, заканчивая составление итоговых таблиц для согласования поставок
4. worker - 
Это исполнитель, есть возможность просматривать задачи которые закрепленные ему работодателем, возможность просматривания своих результатов, и составления таблиц на свой счет
